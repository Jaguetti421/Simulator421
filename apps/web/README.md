# @lastclan/web

The browser application (TP v2.0 §2, §3, §13–§15, §21): Vite static build, the simulation in a Web Worker, Three.js on WebGL2 with a 45° tabletop camera, React UI over view models, IndexedDB persistence adapter, `/capture` route for screenshots.

Nothing of that exists yet — **W0-10** adds the shell, kit, `/capture` and the Playwright job; **P1-27…31** add the snapshot bridge, motions, selection, timeline and feed.

Render-only floats are allowed here and nowhere else (AGENTS.md).

Status: **skeleton only (W0-01)**. Vite is pinned when W0-10 introduces it (noted in state/STATUS.md).
