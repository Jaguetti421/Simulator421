# P1 — First playable

Exit gate: **G1** · 35 bounded packets · Not one chat session.

Eight real autonomous survivors gather, rest, build, wait for laws and react to danger in a readable scene.

## Entry and authorization

Requires accepted G0 and explicit Jani authorization of P1.

A dependency must be ACCEPTED on the current integrated baseline before dispatch. One active packet per owner and at most four builders are the default. A0 may issue a disjoint wave only after contracts are integrated; A7 reviews returns and A0 verifies combined code. A7-authored tools are independently reviewed by A0. No automatic multi-agent spawning is required by this kit; Jani controls the chat windows.

## Exit evidence

- Eight real actors complete food/work/build/wait/threat sequences; mapped law/route/inventory scenes pass.
- All twelve action states, selection/follow/Why/timeline and real capture are readable.
- Save/load agrees for 600 ticks; production query population stress is measured with remaining omissions listed.

The final P1 integration packet prepares templates/GATE_EVIDENCE.md with exact candidate hashes and actual reports. A failed criterion requires a repair packet followed by affected retests; a repair plan alone cannot pass. Use PASS/FAIL/BLOCKED/HUMAN_REQUIRED honestly. Gate evidence is invalidated when later changes affect its behavior; A0 records the targeted revalidation before carrying a gate forward.

## Stop and next step

Agents stop after their assigned packet, even when the next dependency is ready. A0 presents a reviewable phase candidate to Jani and asks explicit permission for the next phase/baseline. Resume of an incomplete authorized packet is allowed; beginning the next packet is a new dispatch. P6 approval never authorizes uploading or publishing the game. Optional PX may remain deferred without changing core scope.
