## Observable acceptance
1. `npm run build` produces a static site; opening it runs the synthetic workload in a Worker at 1x/2x/4x with pause; the page shows the confirmed tick.
2. Eight supplied recipes render as distinguishable procedural characters (build, head, headwear, accessory, clan color, personal accent) at default tabletop distance; mesh bounds and attachment points are recorded.
3. `/capture?fixture=&tick=&camera=&textScale=` renders after warm-up frames and writes a PNG with metadata under Playwright in CI (BLOCKED_RENDER in the sandbox, recorded as such); FakeSim frames carry a visible watermark.
4. Browser Worker hashes equal Node hashes for the workload (closes the W0-07 blocked half).
