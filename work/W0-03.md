## Observable acceptance
1. Vectors identify algorithm, seeding rule and byte order; they are stored in the repository and match the implementation.
2. Adding an unused guest or cosmetic stream does not advance core streams; equal seeds give equal sequences across Node and a browser Worker (verified at W0-07/W0-10).
3. Equivalent data in different insertion order hashes identically; a changed consequential value changes the authoritative hash; observer data changes only the observer hash.
